# claude-card

Shared style for AFTECH decision cards in Claude chat visuals (colors and layout only, no data).
Uses the claude.ai theme variables, so it works in light and dark mode.

Load it pinned to a version:

    <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/aftechnet/claude-card@v1.0.0/card.css">

Classes: `.f` flow row (boxes `.g` green done, `.u` blue this yes, `.a` amber open, `.n` gray later, `.r` red broken), `.o` option row (`.o.p` main), `.t` tag, `.bar` bar row.
Change it with a new tag (v1.0.1, ...) and update the version in the card skill. Never edit a published tag.
